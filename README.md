# 贵州省研学综合服务网静态原型

本仓库包含研学管理与门户页面的可交互静态 HTML 原型。

## 校内外实践免费活动（本次更新）

- `校外实践免费活动.html`：学校端活动管理。新增、列表和详情均展示活动类型（外出／校内）；上传项目由区域资料清单配置，可填写资料名称、说明、允许格式、文件大小上限和是否必传。活动填报页严格按已配置清单展示和校验，不可自行新增资料项。仅预置少量资料作为测试数据。提交后活动共享到教育局审核端。
- `校内外实践免费活动-教育局审核.html`：教育局端审核页面，提供待办、已办、全部列表、活动详情、PDF预览/下载、通过/驳回和审核意见。审核结果写回共享活动数据。
- 学校端及教育局端页面需在同一浏览器和同一网站来源打开，使用浏览器本地存储进行原型数据联动；不是连接真实后台。

## 需求管理：资料提交地址

- `需求管理-后台.html`：后台需求新增与编辑表单。“投标邮箱”改为“资料提交地址”，可自由输入，不做邮箱格式校验。
- `需求公示-详情.html`：详情中展示“资料提交地址”，替代“报价材料递送点”。

## 其他研学区域原型

- `机构集体研学开关.html`：按区域设置学校端是否一并拉取机构清单。
- `基地填报-研学区域.html`：路线规划下新增研学区域选择。
