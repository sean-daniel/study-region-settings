# 贵州省研学综合服务网静态原型

本仓库包含研学管理与门户页面的可交互静态 HTML 原型。

## 需求管理：资料提交地址

- `需求管理-后台.html`：后台需求新增与编辑表单。原“投标邮箱”改为“资料提交地址”，使用普通文本输入，可填写邮箱、网址、网盘链接或其他文本，不进行邮箱格式校验。
- `需求公示-详情.html`：门户需求公示详情。将“报价材料递送点”改为“资料提交地址”，展示对应提交信息。

## 校外实践免费活动

- `校外实践免费活动.html`：活动名称、时间、地点和出行人数管理；新增时上传两份 PDF，详情支持逐份预览和下载；资料清单可按省、市、区县选择并独立维护。

## 其他研学区域原型

- `机构集体研学开关.html`：按区域设置学校端是否一并拉取机构清单。
- `基地填报-研学区域.html`：路线规划下新增研学区域选择。

以上均为静态前端原型，用于展示页面和交互流程。
